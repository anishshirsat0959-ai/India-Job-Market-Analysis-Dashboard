
# India Job Market Analysis Dashboard 2026 📊

## Project Overview
The India Job Market Analysis Dashboard 2026 is an interactive Power BI project created to analyze current hiring trends, skill demand, company openings, and work mode patterns in the Indian IT and analytics industry.

This project was built using SQL, Power BI, and Excel to generate meaningful business insights from job market data.

---

## Objectives
- Analyze job opportunities across different locations
- Identify most in-demand skills in the market
- Compare company-wise openings
- Understand Hybrid, Remote, and Onsite work trends
- Create an interactive dashboard for data visualization

---

## Tools & Technologies Used
- SQL
- Power BI
- Excel

---

## Dashboard Features
### 📍 Location Wise Job Analysis
Shows hiring distribution across different cities.

### 🏢 Company Wise Openings
Analyzes companies with the highest number of job openings.

### 💡 Skills Demand Analysis
Identifies trending skills such as:
- SQL
- Power BI
- Python
- Excel
- PL/SQL

### 🌐 Work Mode Trends
Comparison of:
- Hybrid
- Remote
- Onsite jobs

### 📊 KPI Cards
- Total Jobs
- Average Salary
- Total Openings

---

## Key Insights
- SQL and Power BI are among the most demanded skills.
- Hybrid work mode is highly preferred by companies.
- Pune, Bangalore, and Hyderabad show strong hiring activity.
- Analytics and Business Intelligence roles continue to grow rapidly.
